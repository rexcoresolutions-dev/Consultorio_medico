2. Conectar al sistema de correo los eventos opcionales restantes (citas, documentos, inventario y vigencia) y, si se requieren, plantillas/destinatarios editables.
3. Añadir una interfaz clínica de combinación de versiones para conflictos que no puedan resolverse mediante reintento o descarte.
4. Conectar `docs/` con Andromeda cuando exista una ruta o mecanismo verificable.
5. Compilar instalador Windows, APK debug/release y AAB; la versión release necesita claves externas de publicación.
6. Ejecutar compilación, migraciones y escenarios de aceptación cuando se retire la indicación de no hacer pruebas.
